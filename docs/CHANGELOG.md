# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-08-22

### Added

- Initial release: `SlideToConfirmType` and `SwipeToSubmitType`.
- Named profiles (`default`, `payment`, `danger`, `legal`, `publish`, `gate`).
- Stimulus controller and standalone IIFE (TypeScript + Vite).
- Form themes for Symfony div/table, Bootstrap 3–5, Foundation 5–6, Tailwind 2.
- Translations: `en`, `es`, `it`, `fr`, `pt`, `de`, `nl`.
- Documented use cases for slid submits (pay, delete, publish, legal, cancel, batch, emergency, gate).
